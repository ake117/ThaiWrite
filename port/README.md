## 1. หลักการสำคัญ: ต้นฉบับไม่ถูกแตะ

**กฎเหล็ก: ทุกไฟล์ใต้ `SRC/`, `MANUAL/`, `*.FON`, `*.P24`, `*.P9`, `*.DOC`
คือ source ต้นฉบับของ CU Writer 1.41 — ห้ามแก้เด็ดขาด**

งาน port ของเราทั้งหมดอยู่ใน 2 โฟลเดอร์ของตัวเอง:

```
port/     shim layer + ncurses renderer + notes
tools/    เครื่องมือภายนอก (cw-convert)
```

ตรวจสอบได้ด้วย:

```sh
git diff --stat upstream/master HEAD -- . ':!port' ':!tools' ':!.gitignore'
# ต้องว่างเปล่า = ไม่มีไฟล์ต้นฉบับถูกแก้
```

หรือรัน guard script:

```sh
tools/check-src-pristine.sh
```

เหตุผลของนโยบายนี้:
* เทียบ/rebase กับ upstream ได้ตลอดเวลา ไม่มี merge conflict จาก source ต้นฉบับ
* ส่ง PR กลับ upstream ได้สะอาด (diff เป็นการ **เพิ่ม** ไฟล์ล้วน)
* ข้อบกพร่องของ source ต้นฉบับ (ดูข้อ 5) ถูกจัดการที่ชั้น build/shim ไม่ใช่โดยแก้ต้นฉบับ
* ถ้าจำเป็นต้องแก้จริง ๆ ให้ทำเป็น **build-time patch ลงสำเนา** ใน `build/` เสมอ

## 3. โครงสร้าง

```
port/shim/        แทน header ของ Borland Turbo C 2.01 (dos.h, bios.h, conio.h,
                  dir.h, process.h, io.h, graphics.h, ...) + shim_*.c
                  → libtwshim.a
                  รวมไฟล์ stub ชื่อมี backslash เช่น "..\common\proto.h"
                  เพราะ gcc ไม่แปล DOS separator ใน #include "..\common\x.h"
```

Source ต้นฉบับถูกอ้างอิงผ่าน path สัมพัทธ์ `../SRC` จากใน `port/shim/`
(ใน repo นี้ source อยู่ที่ `SRC/` ที่ root แล้ว ไม่มีสำเนา nested)

## 4. Build

```sh
make -C port/renderer      # libtwrenderer.a + test_renderer
make -C port/shim          # libtwshim.a
make -C port/shim check    # compile-check source ต้นฉบับกับ shim headers
```

Build ด้วย `-std=gnu89` (source เขียนแบบ K&R/gnu89)
`geninc/` เป็น symlink mirror ชื่อไฟล์ตัวพิมพ์เล็ก สร้างอัตโนมัติจาก target `geninc`
(ใช้ `-iquote` ไม่ใช่ `-I` เพื่อไม่ให้ mirror ไปบัง system header)

## 5. ข้อบกพร่องใน source ต้นฉบับ และวิธีจัดการโดยไม่แตะ SRC/

พบ 2 จุดที่ gcc ปฏิเสธ แต่ Turbo C 2.01 แค่เตือน:

1. **`SCUF/TUTIL1.C`** — `proto.h` ประกาศ `thaistrlen(unsigned char *)`
   แต่นิยามจริงเป็น `char *` ⇒ gcc error *conflicting types*
   → **จัดการที่ shim**: stub `port/shim/..\common\proto.h` ให้ประกาศให้ตรงกับนิยามจริง
2. **`SCUP/PRINTING.C`** — บรรทัด ~211–215 มี comment ซ้อน comment (`*/` ข้างในปิด outer)
   เหลือ `*/` โดน parse เป็น expression
   → ต้องเป็น build-time patch ลงสำเนาใน `build/` หรือตัดโมดูล printing ออก
   (สำหรับ CLI export-first โมดูล printing ไม่จำเป็นต่อเป้าหมายหลัก)

ทั้งสองไฟล์ถูก mark เป็น `XFAIL` ใน `port/shim/Makefile` เพื่อให้ `make check`
ยังใช้เป็น gate ได้ตามปกติ

## เสียง (PC speaker emulation)

เพลงจุฬาลงกรณ์มหาวิทยาลัยตอนเปิดโปรแกรม + เสียงเตือน `errorsound()` ใช้ `aplay`
(alsa-utils) เป็นตัวเล่น — shim เขียนคลื่นสี่เหลี่ยม 8-bit 8 kHz ให้ aplay
ผ่านคิวแบบ non-blocking ตัว editor จึงใช้งานต่อได้ทันทีระหว่างเพลงเล่น

- เพลงเล่นเฉพาะตอนรัน `cw` **ไม่ใส่ชื่อไฟล์** (ต้นฉบับเล่นเช่นเดียวกัน —
  ใส่ชื่อไฟล์ตอนรัน โค้ดเดิมจะคิวปุ่ม "พิมพ์ชื่อไฟล์" ซึ่งทำให้ `cusong()`
  เห็นว่ามีการกดปุ่มแล้วข้ามเพลง) · กดปุ่มใดก็ได้ระหว่างเพลงเพื่อข้าม
- ปิดเสียงทั้งหมด: ตั้ง env `CW_NOSOUND=1`
- debug คิวโน้ต: env `CW_TONE_DEBUG` (โน้ตจะพิมพ์ทับลงจอ)

## 7. การแสดงผล (display layer)

แปลง TIS-620 → UTF-8 ที่ขอบ terminal เท่านั้น (0xA1-0xFB → U+0E01-U+0E5B
แบบ 1:1) ส่วน **อักขระเส้น** ของฟอนต์ต้นฉบับ (`NORMAL.FON`) ต้องแปลงเป็น
**Unicode Box Drawing** ไม่ใช่ปล่อยไบต์ดิบ ซึ่งจะกลายเป็น C1 control
ที่ terminal ไม่แสดงผล (กรอบกล่องหายไปทั้งเส้น):

| ฟอนต์ต้นฉบับ | ใช้ที่ | Unicode |
|---|---|---|
| 0x8F / 0x90 / 0x91 / 0x92 / 0x93 | กากบาท + สามแยก | ┼ ┬ ┴ ┤ ├ |
| 0x95 / 0x96 | เส้นนอน / เส้นตั้ง | ─ │ |
| 0x98 / 0x99 / 0x9A / 0x9B | มุมทั้งสี่ | ┌ ┐ └ ┘ |

เส้นกรอบที่ต้นฉบับวาดด้วย `plot()` (`_rectangle`, เวอร์ชันกราฟิกของ
`framebox`) ถูกเก็บใน `port_cell.dot[]` เป็น mask ของคอลัมน์พิกเซลต่อ
กลุ่มแถว (dot[0] = แถว 0-6, dot[1] = 7-13, dot[2] = 14-19) — เส้นนอนเปิด
ทุกคอลัมน์ของกลุ่มเดียว (`0xff`) เส้นตั้งเปิดบิตเดียวซ้ำทุกกลุ่ม
(`0x01` = ขอบซ้าย, `0x80` = ขอบขวา) ตัว renderer เลือกอักษรเส้นบางให้ตรงรูป
โดยดูว่าเส้นต่อไปยังเซลล์ข้างเคียงหรือไม่ (มุม/สามแยก/กากบาท) — **เดิมวาด
เป็นครึ่งบล็อก ▀▄▌▐ ซึ่งทำให้กรอบดูหนากว่าเส้น 1 พิกเซลของต้นฉบับ**

**โลโก้พระเกี้ยว** — `prakeaw()` (EDISP.ASM `_eprakeaw`, HDISP.ASM
`_hprakeaw`) blit bitmap `chulalogo1`/`chulalogo2` (HDISP.ASM:152,157)
ขนาด 32x20 พิกเซล ที่ byte column 1 และ 3 ⇒ คอลัมน์ 1-4 ของแถว 0

**งาน port ย้ายพระเกี้ยวไปวาดในกล่อง splash screen** แทนไทเทิลบาร์ เพราะ
ไทเทิลบาร์มีที่ให้แค่ 4 เซลล์ x 1 บรรทัด — เพดาน 8x4 ดอท ย่อ 32x20 พิกเซล
แล้วเหลือก้อนทึบดูไม่ออกว่าเป็นรูป

- `dispstrhgc` ตรวจจับกล่อง splash (**col 16 แถว 5-13 ที่ใช้ `REVERSEATTR`**
  เท่านั้น — กันชนกับ message box ของ MENU.C ที่ขึ้นต้นที่ col 45) แล้ว
  **ขยายกล่องไปทางซ้าย 16 คอลัมน์** (กว้าง 44 → 60) เพื่อให้มีที่วางพระเกี้ยว
  ในกล่องโดยไม่ล้นขอบ แล้ว **เลื่อนกล่องทั้งใบให้อยู่กลางพื้นที่ที่วาดได้จริง**
  (`splash_base()` = (คอลัมน์ที่มองเห็น − 60) / 2 ⇒ จอ 80 คอลัมน์ได้ขอบซ้าย
  col 10 ขอบขวา col 69 ⇒ เหลือขอบซ้าย/ขวา 10 คอลัมน์เท่ากัน)
- พระเกี้ยววางในกล่องซ้ายสุด **16 เซลล์ x 5 บรรทัด = 32x20 ดอท = 1:1
  กับ bitmap ต้นฉบับทุกพิกเซล ไม่ย่อ** (`port_draw_crest()`) และวาดด้วย
  `REVERSEATTR` เหมือนกล่อง ⇒ **ดำบนพื้นขาว** กลืนกับแถบ splash
- **แถบพระเกี้ยวต้องเป็นพื้นขาวครบทุกแถวของกล่อง (แถว 6-12)** ไม่ใช่เฉพาะ
  5 แถวที่มีหมึก — ถ้าไม่เติม แถวเหนือและล่างตัว logo จะค้างเป็นพื้นหลังเดิม
  และเห็นเป็น **แถบดำคาดบน/ล่าง logo** (`splash_fill()` เติมพื้นขาวก่อน
  แล้ว `port_draw_crest()` วาดรูปทับแถวกลาง)
- หนึ่งเซลล์ = 2x4 ดอทของอักขระ **Braille** (U+2800-U+28FF) เก็บดอทมาสก์
  ใน `port_cell.over`; เซลล์ที่ไม่มีหมึกก็ตั้ง attr เดียวกันเพื่อไม่ให้เป็น
  ช่องดำคั่นกลางแถบ
- `prakeaw()` ของต้นฉบับถูกเรียกตอนเปิดจอ แต่ใน port เป็น no-op (ย้ายการ
  วาดไป splash แล้ว) — ธงไทเทิลบาร์จึงเป็น `┌─────จุฬาลงกรณ์มหาวิทยาลัย`

ลำดับไบต์ของ bitmap: `_hprakeaw` เขียนด้วย `mov es:[di],ax` ⇒ **AL อยู่
address ต่ำ = ครึ่งซ้าย** (little-endian) และภายในไบต์บิต 7 = พิกเซลซ้ายสุด

### ความต่างจากต้นฉบับที่ตั้งใจ (intentional)

- ข้อความที่เปิด `^E` (`ENLARGEATTR`) ได้ความกว้าง 2 คอลัมน์ต่ออักขระ
  เท่าต้นฉบับ แต่ glyph ไม่ถูกยืด — บน terminal จึงเห็นเป็นตัวอักษรห่างกัน
  (หัวกล่อง splash: `C U   W R I T E R`) ไม่ใช่ glyph หนาสองเท่า
  · ช่องว่างครึ่งหลังของอักษรขยายเดิม "ไม่ถูกเขียน" จึงค้างเป็นพื้นหลัง
  เดิมและเห็นเป็นกล่องดำคั่นกลางแถบ reverse — port เติม blank ด้วย attr
  เดียวกันให้แล้ว
- กล่อง splash ถูกขยายไปทางซ้าย 16 คอลัมน์ (กว้าง 44 → 60) แล้วเลื่อน
  ทั้งใบให้อยู่กลางพื้นที่ที่วาดได้จริง (`splash_base()`) — ตำแหน่งข้อความ
  ในกล่องคงเดิมทุกคอลัมน์ แค่เลื่อนตามกล่องเท่ากันทั้งแถว
- `port_cell.over` เขียนไว้ที่ byte 8 ของ `serialize_cell` จึงตามไปกับ
  getwind/putwind เฉพาะเมื่อ caller ใช้ record กว้าง ≥ 9 ไบต์ (เส้นทาง
  ปกติของ DOS ใช้ 1 ไบต์/record) — `prakeaw()` วาดใหม่ตอนเปิดจอทุกครั้ง
  เหมือน flow ของต้นฉบับอยู่แล้ว

## 8. การใช้งานจากบรรทัดคำสั่ง

```sh
cw                    # เปิดโปรแกรม (มีเพลงระหว่าง splash)
cw FILE.DOC           # เปิดแฟ้มข้อมูล CU Writer
cw --version          # เวอร์ชันของ port ที่ build ไว้
cw --help             # ตัวเลือกทั้งหมด
```

`--version` / `-V` / `--help` / `-h` อยู่ใน `port/renderer/port_cli.c`
ด้วย **constructor** (ทำงานก่อน `main()` ของ CW.C) เพราะ main ของต้นฉบับแยก
argv แบบ DOS — ถือว่าอะไรที่ขึ้นต้นด้วย `/` เป็น option และไม่มีช่องว่างให้
option ของ port เลย (พาธแบบ POSIX ยังทำ buffer overflow ได้ด้วยซ้ำ —
ดูเหตุผลของ wrapper ในหัวไฟล์ `~/.local/bin/cw`)

> object นี้ต้องถูกลิงก์ **ตรง ๆ** (`renderer/port_cli.o` ใน `port/Makefile`)
> ไม่ใช่ผ่าน archive — static library จะตัด object ที่ไม่มีใครอ้าง symbol ทิ้ง
> ทำให้ constructor ไม่ถูกเรียก แล้ว `--version` จะตกไปที่ตัวแยก argv ของ DOS

เวอร์ชันฝังตอน build จาก `git describe --tags --dirty --always`

## 9. การคืนสภาพ terminal ตอนออกจากโปรแกรม

ออกด้วย `ALT-X` (หรือโดนสัญญาณ TERM/HUP/QUIT) แล้ว **shell ต้องใช้งานต่อได้**
ถ้าไม่คืนสภาพจะเจออาการ "พิมพ์อะไรก็ไม่ขึ้น" เพราะ terminal ค้างอยู่ที่
cbreak/noecho และ cursor ยังซ่อน

`setgraph()` เก็บ termios **ก่อน** `initscr()` แล้วลงทะเบียน
`atexit(port_cleanup_term)` + signal handler ซึ่งทำ 2 อย่าง:

1. `endwin()` — ออกจาก ncurses (โชว์ cursor, ปิด keypad, ออก alternate screen)
2. คืน termios ที่เก็บไว้

**ทำไมต้องเก็บก่อน `initscr()`:** `shim_raw_mode()` (`port/shim/shim_bios.c`)
บันทึก termios ตอนอ่านคีย์ครั้งแรก ซึ่งตอนนั้น ncurses ตั้ง cbreak/noecho
ไปแล้ว และลงทะเบียน `atexit` ของตัวเองด้วย ⇒ handler ของ shim จึงรัน
**หลัง** `endwin()` แล้วเอา noecho ใส่กลับให้ shell · handler ของ renderer
ที่ลงทะเบียน *ก่อน* จะรันทีหลังและคืนค่าดิบของจริงเป็นตัวสุดท้าย

ตรวจสอบหลังออกจากโปรแกรม: `stty -a | tr ';' '\n' | grep -E 'echo|icanon|isig'`
ต้องเป็น `echo icanon isig` (ไม่มีขีดนำหน้า)

## 10. บั๊กการแสดงผลที่ port แก้

- **เมนูบาร์หาย** — `headmenu()` ของต้นฉบับเขียนชื่อเมนูลงแถวบนสุดแบบ
  reverse video แล้ว `_line()` ขีดเส้นทับแถวเดียวกัน · `render_cell()` เดิม
  ให้ dot (เส้น) ชนะข้อความ ชื่อเมนูจึงหายทั้งแถบ และไอเทมเมนูแถวแรกที่ทับ
  เส้นกรอบกล่องก็หายด้วย ⇒ port ให้ **ตัวอักษรจริง (ที่ไม่ใช่ช่องว่าง) ชนะ
  dot** ในเซลล์เดียวกัน ส่วนเซลล์ว่างยังให้เส้นชนะ กรอบกล่องจึงต่อเนื่อง
  (DOS เห็นทั้งข้อความและเส้นเพราะอยู่คนละแถวพิกเซลในเซลล์เดียว — terminal
  แสดงได้อย่างเดียว จึงต้องเลือก)
- **กล่อง splash อยู่ไม่กลางจอ** — จัดกลางทั้งแนวนอนและแนวตั้ง "ในพื้นที่ว่าง"
  คือไม่นับ UI ด้านบน (แถว 0-3: ไทเทิลบาร์/บรรทัดสถานะ/ruler) และเผื่อกรอบ
  ล่าง 1 แถว · คำนวณจากขนาด terminal จริงทุกครั้ง (`port_visible_cols/rows()`)
- **แถบดำด้านบนและด้านล่างพระเกี้ยว** — แถบพระเกี้ยวกว้าง 7 แถว แต่ bitmap
  สูง 5 แถว แถวที่ไม่มีหมึกจึงเคยค้างเป็นพื้นหลังดำ ⇒ เติมพื้นขาวครบทุกแถว
  ของแถบก่อนวาดรูปทับ
- **ขอบขวาของกล่อง splash ไม่เสมอ** — ช่องว่างท้ายสตริงของแต่ละแถวถูกวาดด้วย
  attr ของกล่อง ขอบขวาจึงยื่นออกมา 1 คอลัมน์ ⇒ ล้างช่องนั้นให้เสมอขอบ
- **กรอบ dropdown menu เป็นปื้ดเทา (`▒`) และมุมกล่องหาย** — ต้นฉบับวาดกรอบด้วย
  `_rectangle()` เป็นเส้น 1 พิกเซลที่คอลัมน์พิกเซลใดก็ได้ · `render_cell()`
  เดิมจับเส้นตั้งได้เฉพาะ bit0/bit7 (ขอบเซลล์) และตัดสินมุมจากบิตในเซลล์เดียว
  (เซลล์มุมมีบิตเส้นไม่ครบ) ⇒ จับเส้นตั้งจากบิตที่เปิดในทุกกลุ่มพิกเซล และ
  ตัดสินรูปมุม/สามแยกจาก**เซลล์ข้างเคียง**
- **เมนูหลักตัวเก่ายังค้างบนจอเมื่อเลื่อนไปเมนูถัดไป** — `savescrn()`/`resscrn()`
  ใช้ `getwind()`/`putwind()` ที่ port ทำผิด: เขียนแค่คอลัมน์แรกของหน้าต่าง
  (ทั้งที่ `bytecount` = จำนวนคอลัมน์) ⇒ คืนเนื้อจอเฉพาะคอลัมน์เดียว ที่เหลือ
  เป็นเมนูเก่าค้าง ⇒ ทำใหม่ตาม layout ของ DOS: `buf[scanline * cols + column]`
  โดยเก็บสถานะเซลล์ 9 ไบต์ใน scanline 0-8 (ขนาดบัฟเฟอร์เท่าต้นฉบับ)

## 11. ค่าตั้งต้นที่ทำให้หน้าจอตรงต้นฉบับ

CU Writer อ่านค่าตั้งจาก `TW.CFG` ในโฟลเดอร์ปัจจุบัน (ไม่พบก็ใช้ค่าที่ compile ไว้)
ค่าที่ compile ไว้ใน `CWSETUP.C` คือ **`rightmargin 65`** ซึ่งแคบกว่าที่ CU Writer
1.52 ใช้จริง (ขอบขวาคอลัมน์ 78) ⇒ ruler/เอกสาร/การตัดบรรทัดสั้นกว่าต้นฉบับ 13
คอลัมน์ และตำแหน่ง element ทั้งแถบเลื่อนไป

repo นี้จึงมี **`TW.CFG` ที่ root** ตั้ง `rightmargin 78` — ประกอบกับ
`wind.col=1, wind.length=78` ใน `CWSETUP.C` ⇒ เอกสารอยู่คอลัมน์ 1..78 เหลือ
คอลัมน์ 79 เป็นกรอบขวา ตรงกับภาพ CU Writer 1.52 ที่รันใน DOSBox (ruler ลงท้าย
`R` ที่คอลัมน์ 78)

> แก้ค่าผ่านเมนู "ตัวเลือก" แล้วโปรแกรมจะเขียน `TW.CFG` ทับ (git จะเห็นไฟล์เปลี่ยน)
> — ไฟล์นี้เป็นค่าตั้งต้นของ port ตั้งใจให้ commit ไว้

## 12. เอกสารเปล่าตอนเริ่ม (wrapper)

`tools/cw-wrapper` (ติดตั้งเป็น `~/.local/bin/cw`) ส่งชื่อ **`NONAME1.CM`** ให้
โปรแกรมเมื่อไม่ระบุไฟล์ — เลียนแบบ CU Writer 1.52 ที่เปิดเอกสารเปล่าชื่อนี้ตั้งแต่
เริ่ม (title bar: `แฟ้มข้อมูล : NONAME1.CM`)

นอกจากจะตรงกับต้นฉบับแล้ว ยังแก้ปัญหา: ต้นฉบับ 1.41 เริ่มด้วย `filename` ว่าง
ทำให้ main loop ไม่เข้าโหมดแก้ไข (`if (filename[0] != '\0')` เป็นเท็จ) ⇒
**กด ESC ในเมนูแล้วเมนูเปิดค้าง** เพราะลูปเรียก `pulled_down_menu()` ใหม่ทันที
· พอมีเอกสารเปิดอยู่ ESC จะปิดเมนูและคืนหน้าจอตามปกติ
